# JOJO PONG

Primeiro jogo experimental da fábrica XEX.

- D-pad para mover a raquete esquerda.
- O adversário é controlado pelo jogo.
- Primeiro a fazer 5 pontos vence.
- A reinicia depois do fim.
- Back sai para a dashboard.

Coordenadas lógicas 1280x720 com escala proporcional para o modo de vídeo detectado.
