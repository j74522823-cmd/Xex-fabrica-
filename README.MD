# Jojo Engine — Xbox 360 Homebrew

Este projeto usa o **xsdk / xenon-tools** da comunidade Free60Project para compilar programas para Xbox 360.

## Agradecimentos
- Aos desenvolvedores do Free60Project e xsdk por disponibilizarem as ferramentas de compilação abertas
- À assistência na elaboração do fluxo de compilação automática via GitHub Actions

> Cada compilação é feita aqui de forma automática. O resultado é para aprendizado e uso pessoal.
